# Правила разработки лендинга для IT-стартапа

## 1. Технологический стек и библиотеки
- **Фреймворк:** React (функциональные компоненты, хуки `useState`, `useEffect`).
- **Стилизация:** Tailwind CSS.
- **Анимации:** Обязательно используй `framer-motion` (`motion`, `AnimatePresence`) для плавного появления элементов и интерактивности.
- **Иконки:** Используй `lucide-react`.

## 2. Визуальный стиль IT-стартапа (Modern Tech Aesthetic)
- **Палитра:** Используй глубокий темный фон (`bg-slate-950` или `bg-zinc-950`) с контрастным белым текстом и яркими градиентными акцентами (`from-indigo-500 via-purple-500 to-cyan-400`). Допускается светлая минималистичная тема, если это указано в промпте.
- **Эффекты стекла и света:** Применяй `backdrop-blur-xl`, полупрозрачные границы (`border-white/10`) и фоновые радиальные свечения (`blur-3xl opacity-20`) за ключевыми блоками.
- **Типографика:** Крупные, плотные заголовки (`tracking-tight font-bold`), акцентные слова выделяй текстовым градиентом (`bg-clip-text text-transparent bg-gradient-to-r`).

## 3. Стандарты анимаций (Framer Motion)
1. **Появление при скролле:** Оборачивай секции и карточки в `motion.div` с параметрами:
   `initial={{ opacity: 0, y: 24 }}`, `whileInView={{ opacity: 1, y: 0 }}`, `viewport={{ once: true, margin: "-50px" }}`, `transition={{ duration: 0.5, ease: "easeOut" }}`.
2. **Каскадная анимация (Stagger):** В сетках карточек добавляй задержку `transition={{ delay: index * 0.1 }}`, чтобы элементы появлялись по очереди.
3. **Микро-интерактивность:** Кнопки и интерактивные карточки должны реагировать на наведение и клик: `whileHover={{ scale: 1.02 }}` и `whileTap={{ scale: 0.98 }}`.
4. **Плавные переключения:** Используй `AnimatePresence` для анимации открытия/закрытия мобильного меню, модальных окон и аккордеонов FAQ.

## 4. Обязательная структура лендинга
1. **Navbar:** Фиксированная полупрозрачная шапка с логотипом, ссылками и кнопкой «Начать бесплатно» / «Запросить демо».
2. **Hero Section:**
   - Бейдж с анонсом новой версии или фичи сверху (например, *«✨ Вышла версия 2.0 с ИИ-агентами»*).
   - Мощный заголовок H1, решающий боль клиента.
   - Поле ввода email + кнопка CTA или две кнопки.
   - **Интерактивный UI-мокап продукта:** Вместо пустой заглушки сверстай стилизованный интерфейс дашборда/терминала/чата прямо на React с живыми элементами.
3. **Trusted By:** Логотипы технологических компаний-клиентов в монохромном стиле (`opacity-60 hover:opacity-100`).
4. **Bento Grid (Преимущества):** Асимметричная сетка карточек (`grid-cols-1 md:grid-cols-3`) с разными размерами ячеек (`md:col-span-2`), демонстрирующая ключевые возможности стартапа.
5. **Interactive Tabs / How it works:** Переключаемые вкладки с демонстрацией сценариев использования продукта.
6. **Pricing (Тарифы):** 3 карточки тарифов (Starter, Pro — выделенный как популярный с подсветкой, Enterprise) с переключателем «Ежемесячно / Ежегодно (скидка 20%)» на `useState`.
7. **FAQ & Final CTA:** Аккордеон с вопросами (с анимацией `AnimatePresence`) и финальный блок конверсии перед футером.
