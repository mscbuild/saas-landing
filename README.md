# CodePulse — ИИ-платформа автоматического ревью кода и поиска уязвимостей

> Разработано по стандарту навыка **`saas-landing`**: React 18, Tailwind CSS, Framer Motion, Lucide Icons, Modern Tech Dark Aesthetic, Bento-сетка и интерактивный UI-мокап в Hero-секции.

---

## 🌟 Ключевые разделы лендинга

1. **Navbar**: Полупрозрачная шапка с эффектом стекла (`backdrop-blur-xl`), логотипом, ссылками навигации и быстрой кнопкой вызова пробного периода.
2. **Hero-секция с интерактивным мокапом продукта**:
   - Анонс-бейдж *«CodePulse 2.0: Глубокий AST-анализ & автофиксы в 1 клик»*.
   - Мощный заголовок H1 и форма захвата рабочего email для подключения репозитория.
   - **Интерактивный UI-мокап Pull Request**:
     - Живая демонстрация уязвимости JWT (CWE-347 / CWE-327) в коде.
     - Интерактивная кнопка **«✨ Применить AI-автофикс с тестами»** — при нажатии в реальном времени подставляет безопасный патч, обновляет индикатор безопасности до 99/100 и переводит PR в статус `Одобрено`.
     - Переключатель режимов: `Diff & AI Fix` и `AST Taint Flow` (интерактивный граф потока данных).
3. **Trusted By**: Логотипы технологических лидеров и живой счетчик проанализированных строк кода.
4. **Bento Grid (Асимметричная сетка возможностей)**:
   - *Карточка 1 (2 колонки)*: Глубокий семантический анализ AST и цепочка Taint Flow с интерактивным выбором узлов (`HTTP Source -> Middleware -> Sandbox -> DB Sink`).
   - *Карточка 2 (1 колонка)*: 0.1% ложных срабатываний и симуляция эксплойтов в eBPF-песочнице ядра Linux (индикатор 99.9% точности).
   - *Карточка 3 (1 колонка)*: 1-Click AI Автофиксы с автоматически сгенерированными Pytest/Jest тестами.
   - *Карточка 4 (2 колонки)*: Непрерывный комплаенс в реальном времени с интерактивным переключателем стандартов (OWASP Top 10, SOC 2 Type II, PCI-DSS 4.0) и экспортом в SARIF/Jira.
   - *Карточка 5 (3 колонки)*: Быстрый старт за 60 секунд с интерактивным окном терминала и кнопкой копирования команды `npx codepulse init`.
5. **How It Works (Интерактивные вкладки)**: 4-шаговый пошаговый процесс от подключения GitHub App до слияния безопасного PR.
6. **Pricing (Тарифы)**:
   - Переключатель «Ежемесячно / Ежегодно (Скидка 20%)» на базе `useState` с мгновенным пересчетом цен.
   - 3 тарифа: *Developer* ($0 навсегда), *Team (Pro)* ($39/$49 с неоновым свечением и бейджем лидера), *Enterprise* (On-Premises & Air-Gapped).
7. **FAQ**: Аккордеон с ответами на ключевые вопросы CTO и разработчиков (Zero Data Retention, скорость CI/CD, сравнение с SonarQube/Snyk, поддержка языков).
8. **Final CTA & Footer**: Высококонверсионный финальный блок с формой и подробный футер с индикатором статуса доступности (99.99% Uptime).

## 🚀 Способы запуска и просмотра

### Вариант 1: Мгновенный просмотр (Без установки зависимостей)
Просто откройте файл `standalone-preview.html` в любом современном браузере (Chrome, Edge, Firefox, Safari):
- Поддерживает полный интерактив (нажатие на кнопки автофикса, выбор узлов Bento-сетки, переключение тарифов, FAQ аккордеон).

### Вариант 2: Локальная разработка через Vite
```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки
npm run dev

# 3. Сборка production-бандла
npm run build
```
